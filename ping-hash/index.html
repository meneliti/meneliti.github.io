📡 Ping-Hash

Uptime monitor berbasis git: setiap probe menghasilkan commit dengan fingerprint SHA-256. Bukti server hidup yang transparan, gratis, dan sulit dipalsukan.

📦 repo GitHub 📄 README snapshot build: 09 Oktober 2026

🔓 Verifikasi Hash

Setiap commit memuat fingerprint SHA-256 dari timestamp. Siapa pun bisa memverifikasi:

# verifikasi entri log
$ echo -n "TIMESTAMP" | sha256sum
# cocokkan 12 digit pertama dgn kolom hash

📊 Cara Kerja

  1. 1. Daemon melakukan probe tiap 1–8 menit (delay acak)
  2. 2. Timestamp di-SHA-256 sebagai fingerprint unik
  3. 3. Hasil (status UP/WARN, RTT, emoji) ditulis ke log harian
  4. 4. Commit otomatis & push ke main
